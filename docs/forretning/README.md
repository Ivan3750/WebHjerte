## Що важливо перевірити самому

- **Холодні листи (markedsføringsloven § 10).** Закон у Данії забороняє розсилати рекламу електронною поштою без згоди, і, наскільки я розумію, це стосується й листів компаніям, а не лише приватним особам. Тому:
  - пиши **персональні 1:1 повідомлення** конкретній людині, а не розсилку;
  - краще через **LinkedIn** або **контактну форму** на їхньому сайті;
  - або спершу спитай дозволу («må jeg sende dig et kort oplæg?»).
  - Перед будь-якою масовою розсилкою проконсультуйся з юристом або revisor.
- **Moms.** Реєстрація обов'язкова, щойно оборот перевищить 50.000 kr за 12 місяців. Ціни на сайті вже включають moms, тож після реєстрації вони не зміняться для клієнтів, але твій дохід з кожного продажу зменшиться на 20 %.
- **Хостинг.** Тариф Vercel Hobby, наскільки я знаю, не дозволяє комерційне використання. Для клієнтських сайтів у плані підтримки використовуй Vercel Pro, Cloudflare Pages або звичайний хостинг.
- **Договір.** Текст у `vedligeholdelsesaftale.md` — це шаблон, а не юридична консультація. Пункти 6.1–6.5 у Handelsbetingelser на сайті кажуть те саме.

## Щомісячна рутина (30 хв)

1. Внести цифри місяця в `tracker.csv`.
2. Порівняти «Omsætning» з колонкою «Mål».
3. Подивитися Search Console: які сторінки ростуть, які ні.
4. Запланувати наступний місяць: скільки листів партнерам, скільки кейсів.
