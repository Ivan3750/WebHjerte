# Highlights Studio (Instagram Highlights для WebHjerte)

Редактор для 4 Instagram Highlights: **Projekter · Udtalelser · Services + AI · Kontakt**.
Усі слайди анімовані, у стилі сайту (темний фон, `#00a8e8`, Unbounded), формат 9:16 (1080×1920).

## Як відкрити
Просто відкрий файл `index.html` у Chrome / Edge / Safari (двічі клікнути). Інтернет потрібен лише для шрифту Unbounded.

## Що можна робити
- **Змінювати порядок:** тягни картки слайдів за `⋮⋮` (або кнопки ▲▼). Перетягни картку на кружечок — слайд перейде в інший highlight. Самі кружечки теж міняються місцями.
- **Редагувати все:** тексти, скріншоти, тривалість, колір акценту, іконка обкладинки (панель праворуч).
- **Додавати / дублювати / приховувати / видаляти** слайди; завантажувати власні зображення.
- **Слайди-відгуки:** є один справжній (Vasyl, VEKA) і 2 приховані порожні шаблони — впиши справжні слова клієнтів і зніми «Приховати».
- Усе зберігається автоматично в браузері. «Зберегти проєкт» — резервна копія у JSON; `Ctrl+Z` — крок назад.

## Експорт (кнопка «Експорт»)
- Відео 1080×1920, 30 fps: один highlight одним файлом, **кожен слайд окремим файлом** (зручно для Stories) або всі 4 highlights.
- PNG поточного кадру та PNG-обкладинки (1080×1920, Instagram обрізає в коло).
- Chrome 126+ / Safari записують **MP4 (H.264)** — Instagram приймає напряму. Firefox дає WebM — треба конвертувати.
- Запис іде в реальному часі: тримай вкладку відкритою.

## Для розробника
`editor.src.html` — вихідник; `assets/` — зображення (скріни кейсів, фото, логотип). Після змін:

```bash
node tools/instagram-highlights/build.mjs   # збирає самодостатній index.html
```
